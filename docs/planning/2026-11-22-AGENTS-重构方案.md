## 架构与领域硬约束(MUST)

- `domain` 零 Spring/DB 依赖——引擎是纯函数(独立 Gradle 模块,ADR-0002/0003 有意为之)
- 角色永不进匹配输入(ADR-0003);等级刻度 1–4;presence 需求为默认,min-level 只用于关键路径
- 用户可见文案中文优先,文案外置
- **永不用 JDBC client**(JdbcTemplate/JdbcOperations)——跨表/投影/批量/级联一律 repository `@Query`/`@Modifying`(ADR-0004 唯一授权扩展点)
- Spring Data JDBC + Flyway;禁 JPA/Hibernate/Exposed/BaseEntity 继承
- 对外只暴露公共 ID(`projectId`/`itemId`),永不暴露内部数字 id;FK 用 `object_id` UUID 列
- migration 用 SQL identity + 命名约束;枚举 = Kotlin enum + VARCHAR + CHECK
- 改 `backend/domain` 实体/引擎签名 → 同步 `docs/architecture/domain.puml`;改 Flyway schema → 同步 `entities.puml`;两图顶部 `hide empty members`,不提交生成图片

## 代码与契约(MUST)

- 尽量 `val`;实体/DTO 不可变 data class;更新用 `copy(...)` + save 用返回实例
- 命名分层:domain 与 persistence 共用裸名(包即命名空间,同文件两用 import 别名);API 线型一律语义后缀(`XxxRequest`/`XxxResponse`),裸名永无三义
- `api` 模块业务垂直切片收敛 `yangzhou.api.business.<slice>`(实体+DTO+service+controller 同包);非业务归 `config`/`security`/`general`/`error`(ADR-0007)
- service fail-fast 抛业务异常;HTTP 映射集中 GlobalExceptionHandler;统一错误形状(code/message/path/可选 fields);校验用 Bean Validation
- OpenAPI + Scalar(不用 Swagger UI/Knife4j);Controller 类级 `@RequestMapping("/api")` 只扛 API 前缀
- **改 REST API 必同步 `backend/script/api.http`**;不加 mapstruct,slice 内手写小 mapper;日志 SLF4J 默认配置,不加 MDC/自定义 logback

## 开发与交付原则(默认,细则见 development.md)

- 票即计划;无 spec 不开工;外科手术式改动,不顺手重构无关代码
- 最简可行实现,不加投机抽象;非平凡行为变更必须带测试
- 格式化走工具链:`gradle ktlintFormat` / `npm run format`(CI 有 format check)
- 声称完成前跑通相关验证(后端 = `gradle build` + `integrationTest` 绿 + bootRun 能启动;**agent 本地验证 ≠ 用户环境验收**——功能+测试代码写完即停,等用户 build/debug,过了再 PR)
- **架构破坏必须显要标注**(spec/PR 专节置顶加粗,不得埋进细节)
- 每验证绿点就地 commit(消息带票号);PR squash 进 main,本地分支永久保留不删

## 环境红线(MUST,细则见 environment.md)
