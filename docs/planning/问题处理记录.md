## A9 一票多分支被拆票连坐成多票一分支(2026-11-17,YPJ-208)
- 症状:主票 208 一支收三子票(223/224/225)代码,子票状态错位(代码完即标 Done),用户两次纠偏。
- root cause(实锤):①开工只读 handoff 未对照 AGENTS「1票1分支」原则,把「避免 V66 冲突」自判为特殊情形未经用户拍板——实际栈式提交逐支 cherry-pick 即可,冲突顾虑不成立;②Done 语义错位:按「代码完+验证绿」记账,流程定义 Done=已合 main。
- 修复:改回逐票分支——每票 yz 建支(入册)→ 从 main(或已验提交)cherry-pick 本切片提交 → 各自 PR 按序合;Done 只在合并后移。
- 预防:拆子票动工前,先写明「票↔分支↔PR」映射并随票状态同步;状态机只有 To Do/In Progress/In Review/Done,Done 门禁=合并。

## A15 甘特行标题溢出叠压 chip + 1 日窗宽屏被 MAX_PPD 夹制(2026-11-18,YPJ-230 实锤)
- 症状:行标题文字画出标题列,叠压行尾 estimate chip(207/208/217/223 全中)并压入条区;1920 屏点「1日」显示 ~1.9 天,与「2日」几乎无差别。fit 视图同样复现。
- root cause(prod 探针实锤:computed style + 截图):①220 把标题包进 Link 后,`variant="caption"` 的 Typography 根元素是 inline span——max-width/overflow 对 inline 无效,noWrap 只剩 nowrap,文本画出 120px 布局盒;②MAX_PPD=720 < 内容宽 1386,1 日窗承诺失效(2/3/5 日窗不夹)。
- 修复:①Typography 加 component="div"(block 化,sx 既有 maxWidth/noWrap 立即生效),加 gantt-title-{number} testid;②MAX_PPD 720→2400(常量一处,±/滚轮/预设统一生效)。
- 预防:MUI Typography 包进 Link/其它非 flex 容器后,根元素 display 会从 blockified 退回 inline——依赖盒模型属性(maxWidth/overflow)必须确认根元素 display;「N 天撑满可视区」类承诺要与缩放上限常量对账。
