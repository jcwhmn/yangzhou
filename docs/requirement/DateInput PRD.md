# DateInput PRD — 分段日期输入(mm/dd/yyyy)

> 来源:YPJ-19(V17-6)2026-10-10 讨论,与实现同步收敛;实现与验收记录见 `docs/spec/0019`。
> 状态:**基本可用**(基线 commit 8bb4494),未尽之处见 §6 后续工作池。

## 1. 背景与定位

- 原生 `<input type="date">` 数字挤在一起、不可控、观感差;自研分段输入替代(web 内 4 文件 8 处)。
- 与 Dropdown(spec 0018)同属 YPJ 自研控件族:统一 theme 无边框底色语言(field `#e9f0f6`、圆角 8、聚焦显边框)。
- 远期候选:随 Dropdown 一起抽为**独立控件包**(见 §6.1)。

## 2. 形态

- 三段 `mm / dd / yyyy`,共 8 个数字位,**相互独立**(点击落位、逐位覆写,无任何整段选中)。
- 每段真实数字输入(inputMode numeric),aria-label 月/日/年;外层 `role="group"` + `data-value`=已提交 ISO(e2e 锚点)。
- 空态灰字 placeholder `mm`/`dd`/`yyyy`;label 上方小字,或 `ariaLabel` 兜底(无可见 label 场景)。
- 附按钮:📅 月历(常显)、× 清除(有值时,可访问名「清除 <字段>」)。
- 两档尺寸:small(行内)/默认(Dialog 表单);宽度调用方覆盖。

## 3. 值契约

- 受控:`value: string`(ISO `yyyy-MM-dd` 或 "")、`onChange(v)` 只在「三段完整」或「清空」时外发——编辑中不污染表单值,放弃编辑即不落库。
- 内部草稿态:不完整 → 失焦保留草稿、不外发;Esc → 恢复已提交值。

## 4. 交互(8 位独立光标模型)

### 4.1 定位

- 点击任一数字位,光标落该位;数字键覆写当前位、光标进一位。
- Tab 进空控件 = click 同权:预填今天、光标位 1。
- Tab 控件内:月→日→年,落位 1(数字保持);年段 Tab 跳出控件进下一个控件;出控件后按 DOM 顺序落焦点(item 详情即 开始日期 → 截止日期 → 优先级)。

### 4.2 录入规则(逐位)

| 位 | 数字键行为 |
|---|---|
| 1 月十 | 0/1 填写进位 2;2–9 智能个位 `0X` 跳位 3 |
| 2 月个 | 0–9 填写跳位 3(13–19 照收,提交钳 12) |
| 3 日十 | 0–3 填写进位 4;4–9 `0X` 跳位 5 |
| 4 日个 | 0–9 填写跳位 5;**上限 31**:位 3=3 时按 2–9 直接记 `31` |
| 5–8 年 | 逐位覆写;满 4 后再按覆写末位 |

- ←/→:位内移动,位首/位尾跨段;年位尾 → 同 Tab 出控件。`/` 同 →。
- Backspace:位内自然删;空段回退上一段。Delete:自然删位。
- 粘贴:整串 ISO `yyyy-MM-dd` 或 `mm/dd/yyyy` 分发三段;单段数字普通入段。

### 4.3 提交与修正

- 失焦/Enter 提交;**越界静默修正、无需提醒**:月钳 1–12(13→12)、日钳当月最后一天(02/31→02/28,闰年自动)、日 0→01。
- 年短写补全(仅月/日已满):`27`→`2027`(2 位按 50 pivot → 19XX)、`2`→`2002`、3 位前补 0;显示与提交值恒 4 位。
- 不完整草稿失焦保留,下次接着改(此时保存拿到已提交值——与原生 date 一致,已知限制)。
- 空值点击/聚焦 → 预填今天,失焦即提交;保空值 = 不点控件或点 ×;Esc 失焦前放弃。

### 4.4 月历

- 📅 弹 Popover:头部 `‹‹ ‹ 年.月 › ››`(跳年/切月);7 列日格,选中=field 底色、今天=描边;点日 → 回填+提交+关闭;「今天」一键回填。
- 文案外置 texts(`t.date.*`)。

## 5. 边界与非目标

- 不做:min/max prop、只读态、datetime、国际化(固定 mm/dd/yyyy 显示,ISO 存储)。
- 越界静默改写是拍板行为,不是 bug。
- 其余 → §6 后续池。
