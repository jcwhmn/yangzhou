## 1. 需求(详细)

### 1.1 背景

YPJ-21 合并后,CI e2e = prod server(build+start)+ **37 例全量**,单跑 ~3m40s。V17 节奏已约定**完整套件 merge 前本地跑**(spec 0014/0021),CI 全量属于重复劳动且拖慢 PR 反馈。

### 1.2 目标

- CI e2e 只执行精简冒烟子集(`--grep @smoke`,~10 例核心链路)
- 本地完整套件跑法**不变**(E2E_FRONT_PORT=3001 …标准命令,37 例全量)
- CI e2e 时长显著下降且保持绿

### 1.3 非目标

- 不加 nightly E2E 兜底(全量门禁 = merge 前本地;若要 nightly E2E 另票)
- 不改任何用例的断言/逻辑——只加标签
- 不做 CI build 缓存优化(build ~1.5min 是剩余大头,另票再议)
- 不加本地 `e2e:smoke` npm 脚本(验收未要求;需要时一行的事)

### 1.4 验收

= YPJ-15 票内验收清单;手工验证见 §3。

## 2. 详细设计(代码级修改计划)

### 2.1 标签机制

标题内嵌 ` @smoke` 后缀(Playwright `--grep @smoke` 匹配标题,零版本依赖,报告/trace 可见)。不用 `test.tag` API(需要 1.5x+ 的 grep-tag 支持,且报告呈现不如标题直白)。

### 2.2 @smoke 用例清单(10 例,选型理由)

| # | 文件:行 | 用例 | 覆盖 |
|---|---|---|---|
| 1 | auth.spec:15 | 登录进首页 | 登录(根基) |
| 2 | projects.spec:5 | 建项目表单——创建并打开看板 | 建项目 + 看板加载 |
| 3 | backlog.spec:5 | V13-S4 Backlog 页就地建项 | 建 item |
| 4 | board.spec:6 | 建 item → 详情 → 评论 → 指派 → 状态 QA → 活动日志 | 详情打开 + 核心全链路 |
| 5 | dashboard.spec:5 | 驾驶舱聚合——我的 items、活跃 sprint、进行中 milestone | 首页驾驶舱 |
| 6 | overview.spec:5 | Overview 五区块——状态分布/信号/我的/风险/Sprint | 项目概览 |
| 7 | milestone.spec:5 | Milestone 管理对话框——建/推进/编辑/删除 | 规划实体 |
| 8 | member.spec:6 | V11 成员池色点——有非终态 item 🟢,无 ⚪ | 成员页 |
| 9 | sprint.spec:6 | V12-S3 Sprint 全链路——建/指派/开始/完成/backlog/历史 | Sprint 流 |
| 10 | release.spec:5 | Release 全链路——段显示/对话框建与补建/发布/拉入/非空删除 409 | Release 流 |

选型原则:登录/建项目/建 item/详情打开(票面点名)+ 六大页面/流程各一;依赖 `project` fixture 的用例天然可单跑(既有约定),无顺序耦合。**不标**:V11-S1(竞态修复过但重)、item-assign 系列(指派引擎有专项)、epic/recycle/错误态类(非冒烟职责)。

### 2.3 修改文件清单

1. 上表 10 个 spec 文件:对应 test 标题尾部加 ` @smoke`
2. `.github/workflows/e2e.yml`:「跑 E2E」step → `run: npx playwright test --grep @smoke`(其余步骤不动:起后端/bootstrap/npm ci/装 chromium 照旧,webServer prod build+start 照旧)
3. `AGENTS.md` E2E 段:补一句「CI e2e.yml 只跑 @smoke 冒烟;完整套件 = merge 前本地全量(标准命令不变)」

### 2.4 不动清单

`playwright.config.ts`(grep 走 CLI 参数;auth project 依赖链不破——grep 后 auth project 恰含 1 例,dependencies 成立)· 后端任何代码 · backend.yml / nightly.yml · 其余 27 个用例。

### 2.5 风险与对策

| 风险 | 对策 |
|---|---|
| grep 后某 project 空 → dependencies 失败 | auth.spec:15 必标,auth project 非空;e2e project 含其余 9 例 |
| 标题 grep 不作用于依赖项目 | auth project(e2e 的 dependencies)整体照跑:实跑 12 例(10 标签 + auth 另 2 例);V11-S1 已带确定性等待,回归无害 |
| 全链路 smoke(board:6/sprint:6/release:5)偏慢 | CI 2 workers 估总时长 2~2.5min(build 占 ~1.5min);实测超预期再调选型 |
| 改标题破坏报告/trce 对照 | 用例内部无标题自引用;@smoke 为纯后缀 |
