## 1. 需求

### 背景(票面)

item 级附件上传/下载:附件表 + S3 兼容客户端抽象(presign 上传),驱动选型 RustFS(自托管 S3 兼容)。抽象接口呼应 VcsGateway 的平台抽象思路(YPJ-40 线)。对标 Plane 免费版 Attachments / kaneo S3。

### 范围

1. **附件表** `attachment`(V38):元数据落库,对象字节不经后端(presigned URL 直传直取);
2. **存储抽象** `ObjectStorage` 接口 + S3 兼容驱动(`S3ObjectStorage`,AWS SDK v2);测试用 Fake(同 VcsGateway 模式);
3. **REST 四端点**(item 子资源):注册并取上传 URL、列表、取下载 URL、删除;
4. **限制**:大小上限(默认 20MB)+ 扩展名白名单(可配置);
5. **集成测试**(Fake storage)+ cleanDatabase 表清单同步;
6. **api.http** 新区块 18 + 负例。

### 非目标

- web UI(另票);
- 病毒扫描 / 缩略图 / 配额 / multipart 后端直传;
- 上传确认回调(presigned PUT 是否成功不做服务端确认,列表无上传状态——known-limit 记 As-built);
- workspace 级 DB 配置(单 workspace 本机部署,yaml 足够;多租户配置面另票);
- RustFS 的 compose 编排(你的环境,本票只提供配置项与手测步骤)。

## 2. 详细设计(代码级修改计划)

### 依赖(api/build.gradle.kts)

- `software.amazon.awssdk:s3:2.31.x`(构建时取最新 2.x)+ `software.amazon.awssdk:url-connection-client`(delete 的 sync 调用;presigner 不需要 HTTP 客户端)。

### V38 迁移(persistence)

`V38__attachment.sql`(照 V28 house 形状 + V34 审计约定):

```sql
create table attachment (
    id          bigint generated by default as identity primary key,
    object_id   uuid          not null,
    item_id     bigint        not null,
    filename    varchar(255)  not null,
    content_type varchar(100) not null,
    size_bytes  bigint        not null,
    object_key  varchar(500)  not null,
    created_at  timestamptz   not null default now(),
    updated_at  timestamptz   not null default now(),
    created_by  bigint,
    updated_by  bigint,

    constraint uk_attachment_object_id unique (object_id),
    constraint uk_attachment_object_key unique (object_key),
    constraint fk_attachment_item      foreign key (item_id) references item (id) on delete cascade,
    constraint ck_attachment_size      check (size_bytes >= 0)
);
create index ix_attachment_item on attachment(item_id);
```

- item 软删(回收站)不动附件行;item 硬删走 FK cascade(S3 对象成孤儿 → known-limit,手工清理);项目 purge 的 `purgeItems` 级联覆盖,无需新 purge 语句。

### persistence

- `entities.kt` 加 `Attachment`(主构造 id/objectId/createdAt/updatedAt,审计四元组照 ItemGitRef 形状);
- `repositories.kt` 加 `AttachmentRepository: CrudRepository<Attachment, Long>`:`findByItemId(itemId)`, `findByObjectIdAndItemId(objectId, itemId)`;
- **AbstractApiTest `cleanDatabase()` 加 `"attachment"`**(排在 `item` 之前,skill 硬规则)。

### api 新切片 `yangzhou.api.attachment`(实体+DTO+service+controller 同包)

- **`ObjectStorage` 接口**(seam,同 VcsGateway 模式):
  - `presignPut(key: String, contentType: String): String`
  - `presignGet(key: String): String`
  - `delete(key: String)`(best-effort,失败由调用方 WARN)
- **`S3ObjectStorage`**(AWS SDK v2):`S3Presigner` 出 URL(10 分钟有效),`S3Client` 删除;endpoint/credentials 从配置构造(path-style 访问,RustFS 需要);
- **`AttachmentProperties`**(`@ConfigurationProperties("yangzhou.attachment")`,归 config):`enabled`(默认 false)、`endpoint`、`region`、`bucket`、`access-key`、`secret-key`、`max-size-mb`(20)、`allowed-extensions`(默认 `pdf png jpg jpeg gif webp txt md csv xlsx docx pptx zip`);
  - bean 装配:enabled=true 且配置齐 → 注册 `S3ObjectStorage`;否则不注册,service 侧判空 → **400「未启用附件存储」**(同「未配置 workspace GitHub PAT」先例);
- **`AttachmentService`**:
  - `register(itemId, filename, contentType, sizeBytes)`:
    - 未启用 → 400;item 不存在 → 404;
    - 校验:sizeBytes ≤ max-size-mb(0 < size)、扩展名 ∈ 白名单(取 filename 最后一个 `.`,大小写不敏感)→ 违者 400(统一错误形状);
    - 落行;objectKey = `attachments/{attachmentObjectId}/{sanitized-filename}`(去路径分隔符,保留扩展);
    - 返回 `AttachmentUploadedResponse(attachmentId, filename, contentType, sizeBytes, uploadUrl)`(presignPut,contentType 回签);
  - `list(itemId)` → `List<AttachmentResponse>`(无 URL);
  - `downloadUrl(itemId, attachmentObjectId)` → `AttachmentDownloadResponse(downloadUrl)`(presignGet);
  - `delete(itemId, attachmentObjectId)` → 删行 + `storage.delete` try/catch WARN(行删不受影响,@Transactional 在 service,存储失败不回滚行删);
  - wire 型 `AttachmentRegisterRequest`(@NotBlank filename / @NotBlank contentType / @NotNull @Positive sizeBytes)与响应同文件;
- **`AttachmentController`**(`@RequestMapping("/api")`,资源段方法级):
  - `POST /items/{itemId}/attachments`
  - `GET /items/{itemId}/attachments`
  - `GET /items/{itemId}/attachments/{objectId}/download-url`
  - `DELETE /items/{itemId}/attachments/{objectId}`

### 测试(backend-testing skill)

- **集成**(extends AbstractApiTest + `@Primary FakeObjectStorage` TestConfiguration,同 FakeGatewayConfig 先例):

  - 列表 / 下载 URL(fake 记录 presignGet)/ 删除(行消失 + fake.delete 调用);

### 否决的备选

- **后端 multipart 直传再转 S3** → 字节过后端,内存/超时负担;presign 是票面明示方向;
- **workspace 级 DB 配置面** → 单 workspace 本机部署,先 yaml;配置面 UI 另票;
- **上传状态机(PENDING→UPLOADED 确认)** → 无事件回调的前提下只能轮询 HEAD,复杂度不值;known-limit 记录;
- **MinIO client SDK** → AWS SDK v2 是 S3 兼容生态标准,RustFS 官方即按 S3 兼容对接;path-style 已覆盖。
- ** virus 扫描/配额** → 非目标,不加投机抽象。
