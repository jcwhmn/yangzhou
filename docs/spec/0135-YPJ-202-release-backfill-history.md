# spec 0135 — YPJ-202:US-R5 事后补建 + US-R6 挂接变更留痕

> PRD v1.2 §6 US-R5/R6;前置 spec 0132(#218)/0133(#219)。UI 展示属 R9/后续票,本票只做后端。

## 一、需求

### 范围

1. **US-R5 事后补建**:`POST /api/projects/{key}/releases` 支持 `status=released` + 可选 `releasedDate`(缺省=今天,Clock),用于补录历史发布(Historical Release)。
2. **US-R6 挂接变更留痕**:新表 `release_item_history`,挂接/摘除(含换挂触发的摘)各记一行(action/actor/时间);查询端点 `GET /api/projects/{key}/releases/{releaseId}/history`(倒序)。

### 非目标

- 留痕 UI(前端展示 defer,R9/另票);item 侧 history 端点(需要时另加);release 字段级审计(名称/日期改动不留痕,PRD 只要求 scope 变更记录);批量挂接。

### 真值表(create × status)

| 请求 | 结果 |
|---|---|
| create {name} (status 缺省) | 201,planned(现状不变) |
| create {name, status:"planned"} | 201,planned |
| create {name, status:"released"} | 201,released,releasedDate=今天 |
| create {name, status:"released", releasedDate:"2026-01-01"} | 201,released,releasedDate=该日 |
| create {status:"released", releasedDate 未来日} | 400(补建是历史,未来日不合语义) |
| create {status:"其他值"} | 400 |
| create 无 name | 400(不变) |

### 留真值表(setMembership × 留痕)

| 动作 | 留痕行 |
|---|---|
| 挂(planned,新建行) | `attached` 1 行(release_id=item 挂入的 release) |
| 挂同一 release(幂等 200) | 不留痕(无变更) |
| 摘(planned 行删除) | `detached` 1 行 |
| 摘(无挂接,幂等 200) | 不留痕 |
| 挂到 released | 409,不留痕 |

## 二、详细设计

### 迁移 `V65__release_item_history.sql`

```sql
create table release_item_history (
    id                bigint generated by default as identity primary key,
    object_id         uuid not null,
    release_object_id uuid not null,
    item_object_id    uuid not null,
    action            varchar(20) not null check (action in ('attached', 'detached')),
    actor_member_object_id uuid,
    created_at        timestamptz not null default now(),
    constraint uk_release_item_history_object_id unique (object_id)
);
```

(与 release_item 同构:弱引用无 FK;history 行**永不删**——release 删除也不清 history,补建/审计靠它。)

### persistence

- `Entities.kt`:`ReleaseItemHistory(releaseObjectId, itemObjectId, action: String, actorMemberObjectId: UUID?, @CreatedDate createdAt)`。
- `Repositories.kt`:`ReleaseItemHistoryRepository`:`findByReleaseObjectIdOrderByCreatedAtDesc(objectId): List<ReleaseItemHistory>`。
- cleanDatabase 清单加 `release_item_history`(release_item 之后、release 之前)。

### api(release 切片内)

- `CreateReleaseRequest` 加 `status: String? = null`、`releasedDate: String? = null`;create 校验:status 只允许 null/"planned"/"released"(其他 400);status=released 时 status 直接落、releasedDate=parse 或 today();未来日 400。released create 同样过 leaderGuard(不变)。
- `setMembership` 挂/摘成功路径各插一行 history(actor=`memberService.current().objectId`,照 ItemService 用法);幂等路径不插。
- `GET /api/projects/{key}/releases/{releaseId}/history` → `List<ReleaseItemHistoryDto(itemObjectId, itemName, action, actorMemberId?, actorName?, createdAt)>`;item 名经 `items.findByObjectId` 取(release 软删的项目校验同 find());actor 名经 memberService 现有查名路径,取不到就 null。

### 连带动词

- `docs/architecture/entities.puml`:+ReleaseItemHistory 实体与 Release/Item/Member 关系(改 schema 必同步,AGENTS 硬规)。
- `backend/script/api.http`:release 区块加「补建 released」与「history」请求(自含前置);负例区加未来日/非法 status。
- `docs/architecture/domain.puml` 不动(domain 引擎未改)。

### 否决的备选

- **复用 item_activity 记 release 挂接**:审计视角在 release 侧(PRD scope 变更记录),跨实体塞 item 活动流语义混;独立表清晰。
- **history 带 release 快照字段(releaseName 等)**:release 名可改,留 release_object_id 弱引用、查询时 join 即可;冗余快照是投机。
- **摘 released 历史行也留痕**:0133 已定摘只删 planned 行、released 行不可动,无摘事件。

## 三、手工测试用例(api.http,8082)

1. 补建:`POST releases {name:"v0.5 补录", status:"released", releasedDate:"2026-06-01"}` → 201,回 status=released + releasedDate=2026-06-01;列表排 released 区。
2. 补建缺省日:`status:"released"` 无 releasedDate → releasedDate=今天。
3. 负例:releasedDate 未来日 → 400;`status:"bogus"` → 400。
4. 留痕:挂 item 到 planned release → `GET .../history` 见 attached 1 行(actor=当前用户,名字回显)。
5. 摘 → history 增 detached 行,行数 2,倒序(detached 在前)。
6. 幂等:重复挂同一 release / 对无挂接 item 摘 → history 行数不变。
7. 挂到 released release → 409,history 不增。
8. 删 planned release(摘空后)→ history 行仍在(查同 releaseId history 仍返回)。

## As-built

- 落地与设计一致;两处偏差修正:
  1. history 端点不要求 release 活着(删后仍可查):项目存在性校验 + 直查 releaseId,跨项目仍 404(设计即「弱引用悬空行照返」,首版误用 find() 导致删后 404,集成测试抓出)。
  2. itemName 回显 = item.title(Entities 裸名里 item 字段是 title 非文字 name)。
- actor 取 `memberService.current()`(挂/摘操作者);幂等路径不留痕,同设计。
- 验证:`gradle build` 绿;`gradle integrationTest --tests yangzhou.api.business.release.*` 绿(含新增 US-R5 集成 1 例 + US-R6 留痕 1 例);US-R5 单元 4 例;api.http 新增补建/history/未来日负例三节。
