# spec 0140 — YPJ-219 甘特 S2:时间轴视口 + 六级缩放

> 需求源:`docs/requirement/甘特图 PRD.md` §二R4/R6、§六A 级「今日线入视口」、§九。前置:S1(spec 0139)已合。

## ⚠ 架构影响声明

无破坏。纯前端改造(甘特单页),契约零变化。

## ① 需求(范围/非目标)

**范围**:
- **横向滚动视口**:时间轴从「全跨度压 100%」改为像素制——内容宽度 = 跨度天数 × 每档像素,容器 overflow-x 滚动;左侧标题列(280px)固定不随滚。
- **六级缩放**:年 / 季 / 月 / 周 / 日(逐日)/ 时(单日 0–24 整点)。参考像素密度(可调):年 2px/天、季 6、月 15、周 40、日 120、时 1200。
- **今日线自动入视口**:进页与切档后 scrollLeft 定位到今日线居中(≥今日可见即可,首末日附近夹紧)。
- **时档基准日**:今日;**基准日可导航**(◀ 前一天 / 后一天 ▶ / DateInput 指定日期,用户拍板 2026-11-17);今日无任何条时仍显示空轴。
- 刻度标签按密度抽稀(沿用现策略,阈值按像素宽)。

**非目标**(后续票):范围过滤(S3)、泳道(S4)、计划/实际线(S5)、拖拽编辑、依赖连线、hover 预览卡(A 级小件票)、折叠聚合徽标。

**拍板结果(2026-11-17 用户拍板)**:本期**不做**工作制轴——日/时档统一 **0–24 墙钟全程,不跳周末**;时档刻度密度自适应(按标签像素宽自动取 1/2/3/6h 步长,总轴恒 0:00–24:00);工作日历仅用于条铺排(已落地)。8h 工作制刻度(跳周末)+排期自动顺延 → **新立 backlog 票 YPJ-226**,不在本票。

## ② 详细设计(代码级)

仅改 `web/app/p/[key]/gantt/page.tsx`(+ 必要时 dates.ts)。

1. **档位表**替换现 GRANULARITIES:`year|quarter|month|week|day|hour`,各档 `{pxPerDay, tickUnit}`;hour 档特殊:span 固定为基准日一天。
2. **像素制布局**:外层 Box `overflow-x: auto`;内层定宽(跨度天 × pxPerDay,最小=容器宽);刻度行与条区同宽同偏移,今日线/条全部改 px 绝对定位(`xOf` 返回 px 而非 %)。行标题列 sticky 左侧(现结构是外层 flex 左 280px + 右区,改为右区内部滚动即可,标题列天然不动)。
3. **刻度生成**:按档取整点(年=1/1、季=1/4/7/10 的 1 日、月=每月 1 日、周=周一、日=每日、时=基准日 0–24 整点);抽稀按「标签宽 ≥ 48px」换算为 tick 间距 px。
4. **今日线定位**:挂载与档位切换后 `scrollLeft = clamp(todayX − 视口宽/2)`;今日线随滚绝对定位。
5. **时档数据**:条照画(px 制自动适用);基准日 0–24 全程轴,刻度 24 条整点标签(0:00…23:00),密度不足时自动抽稀为 2/3/6h 步长(不跳周末语义仅与周末无关;周末跳过归 YPJ-226)。
6. B1/B3/汇总条/置灰逻辑不动(px 化仅换坐标函数)。

### 操作流程(状态×动作真值表)

| 状态 | 动作 | 行为 |
|---|---|---|
| 任意档 | 进页 | 默认「月」档;滚动定位今日线居中 |
| 任意档 | 点档位按钮 | 换 pxPerDay 重建轴;再定位今日线 |
| 时档 | 进入 | span=基准日 0–24(默认今日);◀/▶/DateInput 切基准日,轴与条重建并回中 |
| 非时档 | 切基准日控件 | 不显示(仅时档有) |
| 跨度小于视口 | 任意 | 内容宽=视口宽(条仍按比例),无横滚 |
| 滚动 | 拖横滚条 | 刻度与条同步移动;标题列不动 |

## ⚠ v2 设计重定向(2026-11-17 手测反馈 5 点,待用户确认后实施)

**架构影响:推翻「年/季/月/周语义档」轴模型,改为「数据锚定 + 自适应刻度 + 连续缩放」。置顶显要标注。**

### 反馈清单(现状问题)

1. 1日/2日/3日选项应放在时线(日窗)页面内部切换,不是外部大档位——采纳。
2. 2日线 header 应两行:上行=日期边界、下行=时间刻度;总刻度数目标 8–12 个,不要密密麻麻——采纳,成为刻度算法核心目标。
3. 日线看不到 item 线段——待归因(假设:档位语义混乱导致窗口与数据错位;新模型下统一回归验证)。
4. 周线看不到 item——同上待归因。
5. **根本性问题**:轴应由**数据自身的时间范围**决定(如 sprint 全区间 11-19 00:00 → 11-24 08:00),刻度铺满全区间包含所有 item,再通过缩放看细节——而不是按年/季/月/周语义切档。此思路推翻现有档位模型。

### v2 新模型(设计)

**轴 = 数据锚定**:
- 轴范围 = [min(全部 item start, 今日−3d) , max(全部 item due, 今日+3d)](今日±3 保留,保证「现在」可见)。
- 不再有语义档位;横轴恒表示整个数据区间。

**刻度 = 自适应两级**:
- 步长梯子:`1h, 2h, 3h, 6h, 12h, 1d, 2d, 7d, 14d, 1mo, 3mo, 1y`;
- 取**最小步长使得总刻度数 ∈ [8,12]**(上限防密,下限防空);
- 两行 header:上行=粗边界(步长≥1d 时为日期日界;小时级步长时为 0 点日界),下行=细刻度(时间/日期);
- 例:sprint 11-19 00:00→11-24 08:00(约 5.3 天)→ 步长 12h → 11 个刻度;上行标 11-19/11-20/…日界,下行标 00:00/12:00/…。

**缩放 = 连续系数,非档位**:
- 工具条:`− / 缩放滑杆(或 ± 按钮) / +`,pxPerDay 在 [最小(全区间压一屏), 最大(1h/30px≈720px/天,细节级)] 连续变化;
- 刻度随缩放自动升/降步长(梯子联动),始终维持 8–12 个主刻度;
- 日窗预设(1/2/3/5 日)保留为**视口预设按钮**(快速跳到「以今日为中心的 N 天」),不再是轴定义;
- 「今日」按钮:一键回中今日线。

**语义保留**:条渲染(px)、汇总条、FINAL 置灰、孤儿兜底、B3 含当天(date-only)全部不变——只换轴与刻度生成。
