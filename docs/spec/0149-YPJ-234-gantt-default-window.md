# spec 0149 — YPJ-234 甘特缺省视窗:fit + pxPerDay 下限(案 B 修订版)

> 票:YPJ-234(3h,sprint V31,排期 2026-12-01)。拍板 2026-11-19(用户):案 B 修订——**缺省不居中**;「今天 button」= 显式动作(现成按钮)。
> R2 深化(亚日窗放大)/ R3 刻度分层归 YPJ-241,本票不含。

## 一、需求

### 症状
缺省视窗 fit 压全区间:数据跨度一宽(>~2 年),fit 的 pxPerDay 掉到 0.x,所有条压成几个像素,不可读。

### 拍板语义(案 B 修订版,2026-11-19)
1. **缺省缩放 = max(fit, pxPerDay 下限)**:窄区间(fit ≥ 下限)行为不变——全区间恰好一屏;宽区间(fit < 下限)用下限,内容溢出可横向滚动,**条保证可读**。
2. **不遗漏**:溢出部分经滚动全部可达;轴范围不变(数据锚定,0140 v2)。
3. **基本占满画幅**:下限保证 timelineW ≥ 跨度×下限 > 一屏(触发溢出时),无「缩在角落」形态。
4. **今日居中不进缺省**:挂载时今日线入视口(0147 既有,每挂载至多一次)保留;「今日」按钮 = 显式居中入口(已存在,见 §二)。

### 语义断言(⚠ 请人复核)
- 「挂载时今日线入视口」按 0147 既有行为**保留**(滚至视口中部一次)——读作「入视口」而非「缺省居中」;若认为拍板应一并去掉,告知改语义。
- 「-」缩小仍可显式压破下限直至 fit(下限只约束**缺省态**,不约束用户显式缩放)。
- 「全览」按钮语义从「全区间压一屏」变为「回缺省视窗(fit+下限)」——宽区间下不再压满一屏,与拍板一致。

### 非目标
- 不改轴范围锚定、± 缩放 clamp、日窗预设(1/2/3/5)、savedView 持久化结构。
- 不做亚日窗放大(MAX_PPD 抬高)与刻度分层重设计 → YPJ-241。
- 不动后端。

## 二、详细设计(代码级)

### 改动 1:`web/app/p/[key]/gantt/page.tsx` — 缺省缩放下限
常量区(L70 旁)加:
```ts
const GANTT_MIN_PPD = 3; // 缺省视窗 pxPerDay 下限(YPJ-234 拍板:宽区间不把条压没;1 天 ≈ 3px、1 月 ≈ 91px 可读)
```
轴 memo(L243):
```diff
- const pxPerDay = Math.min(Math.max(zoom ?? fit, fit), MAX_PPD);
+ // 缺省态(null)= fit 但带下限;显式 zoom 仍 clamp [fit, MAX](用户可压破下限)
+ const pxPerDay = Math.min(Math.max(zoom ?? Math.max(fit, GANTT_MIN_PPD), fit), MAX_PPD);
```
「全览」按钮注释同步:「全览:回到缺省视窗(fit+下限)」。其余零改动:`zoomTo` clamp 不动、`applyDayWindow` 不动、挂载自动滚 effect 不动。

**否决的备选**:
- 案 A(今日为中心 N 日窗)——拍板否决:截断集合外 item。
- 缺省态 clamp 到 [floor, MAX](连显式「-」也拦)——否决:下限是缺省可读性约束,不是缩放硬界;用户显式压缩是自主行为。
- 改 `zoomTo` 下界为 floor——同上,且与「-到底=fit」既有心智冲突。

### 「今日」按钮:品味两案(动工前请拍板其一)
现状:`gantt-today` = `goToDayWindow(null)` = **缩放重置为缺省(null)+ 今日居中**。
- **案甲(零改动)**:维持现状。深缩放时按「今日」会被拉回缺省窗——与「全览」功能重叠。
- **案乙(推荐,小改)**:今日 = **只居中不重置缩放**(`setCenter(今日)` + 重置 lastCenter refs,不动 zoom)。缺省不居中之后,「今日」是唯一居中入口,不该偷换缩放;回缺省缩放已有「全览」。改动 = onClick 换一个 6 行函数。
- e2e 影响两案皆无(现有用例在未缩放态点今日,行为一致)。

## 三、手工测试用例(用户 build/debug 阶段执行,dev 实例 3001)

前置:YPJ 项目甘特页(现成数据);再造一张 2024 年的 item 制造宽跨度。
1. 宽区间缺省:打开甘特 → 出横向滚动条,条不再压成线(≥3px/天),月标签可读;今日线自动入视口一次。
2. 窄区间回归:删掉老 item(或切只有近期 item 的 scope)→ 缺省仍全区间一屏,与现在一致。
3. 点「今日」:按所选案(甲/乙)核对缩放是否被重置;今日线居中。
4. 点「全览」:宽区间下回缺省窗(ppd=3)而非压满一屏;视口位置不动。
5. 「-」到底:可压破 3 直到 fit(全部一屏),「+」到 2400 上限不变。
6. 刷新/切 scope 回来:缩放与滚动位按存档恢复,缺省态(全览后)也恢复为 fit+下限。
