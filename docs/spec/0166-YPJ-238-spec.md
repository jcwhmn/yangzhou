# 0166 — YPJ-238 看板列内 item 手工排序(方案 B:看板视图级 board order,spec=需求+设计合一)

> 票:YPJ-238(看板列内 item 手工排序;用户拍板方案 B 2026-11-26)
> 上游:ItemGroup PRD(看板 Phase);YPJ-233 甘特行序与本票无关联(甘特按 start 排,不消费 board order)。

## 一、目的与范围

看板 status 列内的 item 顺序可由用户手工拖拽排定并持久化;排序是**看板视图级记忆**(方案 B:项目 × item 粒度),与组/sprint 归属脱钩——换组、rollover 后顺序不跟随。

### 1.1 非目标
- 组内 position(item_group_member 不动,方案 A 否决);
- 甘特行序、表格视图排序(各自体系不变);
- 多套具名看板视图(228 另票);
- 列间排序语义(列序 = workflow position,不变)。

## 二、术语

| 术语 | 义 |
|---|---|
| board order | 项目 × item 的看板排序记忆(position INT);无行 = 未排过 |
| 列内排序键 | boardOrder ASC(有行)→ number 自然序(无行,沉底) |

## 三、数据语义

- 新表 `board_item_order`:`id identity` / `object_id uuid unique` / `project_object_id` FK project / `item_object_id` FK item(双 cascade)——**行存在 = 该 item 在看板上且已有列内位次**;backlog 不留行;
- `position int not null check (position >= 0)`;无列内唯一约束(允许空洞/重复,写入端全列重排保证单调);
- **每列独立序列(用户拍板 2026-11-26 ①)**:排序键 = 同列内 position ASC → number(无行沉底);跨列不比较;
- **生命周期(用户拍板 2026-11-26 ①②③)**:
  - 状态迁移(拖列/详情/CLI PATCH):item 已有行 → 重置为新列**末尾**(该列 max+1);同批迁移按提交序依次 max+1,**相对顺序保持**;无行 → 仍无行,沉底按编号;手工重排后以手工为准;
  - 退出看板回 backlog(移出 active sprint / 看板二元 off):**删行**;
  - 新 item 进看板:不建行,缺省排当前列**末尾**(无行沉底,零钩子);
  - item 转 FINAL:仍留看板(Done 列),行随迁移规则走;
- **写入语义(move 交换,2026-11-24 用户拍板取代全列重排)**:`POST /api/projects/{key}/board-order/move`,只动新表,至多 2 行 position 写;前端拿响应就地换序,零全量刷新;
- **读语义**:`GET /api/projects/{key}/items` 的 ItemDto 增 `boardOrder: Int?`;排序在前端做(键:boardOrder ?? ∞ → number);
- CLI 同能力(同 move 端点):YPJ-273 另票,238 后紧接。

### 3.1 REST 契约(2026-11-24 修订;全列 PUT 已删,不存在旧端点)

| 项 | 值 |
|---|---|
| 接口 | `POST /api/projects/{key}/board-order/move` |
| 请求体 | `{ "itemId": "<uuid>", "dir": "up" \| "down" }` |
| 语义 | 该 item 与其所在列显示序中的相邻项交换位次(dir=up 与前一项换,down 与后一项换);列 = 该 item 当前 status 的看板可见子集(onBoard ∨ active sprint 成员) |
| 成功响应 | `200` `MoveBoardOrderResponse { "status": "<状态名>", "ordered": [ { "itemId": "<uuid>", "boardOrder": 0 }, … ] }` —— ordered = 交换后该列完整顺序;交换中涉及的沉底项被物化(均有非空 boardOrder);前端用 ordered 就地更新该列,不重新拉看板 |
| 位次规则 | 两行都有 → 纯 swap 两值;涉及沉底行(null) → 升位者继承对方 position,降位者落该列 max+1;两 null 相邻互换 → 双双物化 max+1/max+2(至多 2 行写) |
| 边界 | 列首 up / 列尾 down → 200 无操作(ordered 返回当前序) |
| 错误 | 404 item 不存在或不属于该项目;400 dir 非法;统一错误形状(code/message/path/fields) |
| 不变量 | 每列 position 集合经任意次 move 仍单调无重复(swap 保多重集;物化取 max+1);迁移沉底/退板删行钩子不变 |

## 四、分支真值表(看板 × 拖拽 → 行为)

| 场景 | 行为 |
|---|---|
| 同列:拖 A(任意落点) | 无操作(2026-11-23 用户拍板:列内排序取消拖拽,改为列头排序按钮 + 卡片上下箭头;拖拽仅保留跨列迁移) |
| 排序模式:点上/下箭头 | 与相邻卡交换位次(move 端点,至多 2 行写);响应就地换序;列首无上箭头、列尾无下箭头 |
| 跨列:拖 A(落卡或落空白同语义) | 仅状态迁移(现状);有行 → 重置为新列末尾(max+1) |
| 状态迁移(详情页/CLI PATCH) | 有行 → 新列末尾 max+1;同批迁移按提交序保持相对序 |
| 退出看板回 backlog | 删行 |
| 新 item 进看板 | 不建行,缺省列尾(沉底) |
| 无 order 行的列 | number 自然序(现状) |
| item 转 Done/删除 | Done 列照排;删除行级联清(cascade) |
