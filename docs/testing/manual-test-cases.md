## YPJ-244 甘特渲染+表单后写者为准(spec 0151)

### A. 甘特渲染(切片 1)

- [ ] A1 建票:start=今天 09:00、estimate=8h(不填 due)→ 登记工时(actualStart=今天)→ 甘特:蓝计划条上有**绿色填充**,末端=今天位置
- [ ] A2 该票 estimate 改 16h(233 due 自动重算为明天)→ 刷新:条变长,填充占比变小
- [ ] A3 进行中票 due=昨天(已过期)→ 绿填充**满条**
- [ ] A4 票完成后(FINAL)→ 填充消失;计划条蓝、实际条绿(不再置灰)
- [ ] A5 B 票无 start/due,加依赖 dependsOn A(A 有 due)→ B 行**蓝点**在 A 的 due 处;hover 显「锚点:xx(依赖落位)」
- [ ] A6 C 票无 start/due 直接迁 In Progress → 计划层蓝点在 actualStart + 绿实际条延伸到今天
- [ ] A7 D 票无日期直迁 Done → 实际层完成时刻零宽绿条(小点状)
- [ ] A8 既有元素回归:双条上下错开/深绿遮罩/±Nd 偏移/琥珀菱形/父汇总橙条,无错位无错色
- [ ] A9 **行对齐(2026-11-20 A32 修复)**:长标题票(229/230/231 等中文长题)标题单行显示、列内横滚可看全;标题行与甘特条逐行对齐;同工时票条长一致
- [ ] A10 图例:无「灰=已完成」句;含「绿填充 = 已流逝(用实际色覆盖计划)」「蓝点 = 依赖锚点落位」

### B. 表单互算(切片 2 + 243 联验)

- [ ] B1 票有 start:先改 estimate=2h **再改** due=后天 → 保存:底部 toast;estimate 自动变为反推小时数(≠2)
- [ ] B2 反向:先改 due 再改 estimate=2h → 保存:estimate=2h 生效,due 重算
- [ ] B3 清 due 保存(estimate 有值)→ due 回填 + toast
- [ ] B4 未排期票(无 start)只改 due 保存 → toast「无开始日期,预估未推算」
- [ ] B5 estimate 强制项目:填 start 不填 estimate 保存 → 400 拦截(既有)
- [ ] B6 预估下拉从「未填」直接选「自定义」→ 数值框出现可填(A31 修复:原死锁)
